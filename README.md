# Engrew Labs

### AI & Web3 Technology Platform

**Live Website:** https://www.engrewlabs.org/

## Overview

Engrew Labs is a technology platform focused on AI, Web3 and emerging digital technologies. The website provides a modern digital presence for the organization, presenting its technology solutions, services and areas of focus.

I worked on the **frontend development** of the website, building responsive interfaces, implementing page layouts and translating the design direction into a functional web experience.

## My Role

**Frontend Web Developer**

I was responsible for the frontend implementation, responsive layouts, UI components, styling and interactive elements of the website.
